# Buddha Divers · Web

Web estática (HTML + CSS + JS, sin dependencias) para Buddha Divers, centro de buceo de referencia en Tarifa.

## Ver en local

Abre `index.html` en el navegador, o sirve la carpeta:

```bash
python3 -m http.server 8000
```
