# Saretha: pasos en Hostinger

Web definitiva lista en `saretha-entrega/saretha-web.zip` (código en `saretha-web/`).
Sitio de prueba ya creado: fleet-mediumorchid-oryx-72.hostingersite.com (plan Business).

## 1. Transferir saretha.es (lo que hay que pagar)
1. hPanel → Dominios → Transferir dominio → `saretha.es`.
2. Código de autorización: el del correo de mrubio (20-nov, 5:45). No guardarlo en archivos.
3. **PARAR en el carrito.** Precio esperado: transferencia 0,99 € + IVA (≈1,20 €).
   Renovación a partir del año siguiente: 9,99 € + IVA (≈12,09 €/año).
   Revisar que no añada extras (privacidad, correo, años de más).
4. Si Hostinger avisa de bloqueo, privacidad o DNSSEC: hay que quitarlos en el proveedor actual (lo hace quien lleva hoy el dominio).
5. Tarda de 1 a 7 días. La web vieja de saretha.es sigue hasta entonces.

## 2. Cuando la transferencia termine
1. Websites → sitio de prueba → Cambiar dominio → `saretha.es` (con DNS de Hostinger).
2. Subir el contenido de `saretha-web.zip` a `public_html` (sustituye al de prueba; ya no lleva el aviso de prueba).
3. Activar SSL y comprobar https://saretha.es y https://www.saretha.es.
4. Quitar «Ocultar para buscadores» del sitio.
5. Google Search Console: dar de alta saretha.es y enviar `sitemap.xml`.
6. Opcional: perfil de Google Maps de la tienda con el enlace a la web.
